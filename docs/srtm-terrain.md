# NASA SRTM в AGRONA

Используется [NASA/JPL SRTM Global 1 arc second V003](https://doi.org/10.5067/MEaSUREs/SRTM/SRTMGL1.003).
Разрешение 1″, около 31 м вдоль меридиана, расстояние между долготными
ячейками уменьшается к полюсам. Данные получены в феврале 2000 года,
высота привязана к геоиду EGM96. Покрытие суши от 56° ю. ш. до 60° с. ш.;
V003 использует заполнение пустот дополнительными источниками.
[Руководство NASA LP DAAC](https://lpdaac.usgs.gov/documents/179/SRTM_User_Guide_V3.pdf)

Данные NASA открыты для использования с указанием источника и DOI.
Отдельные [условия OpenTopography](https://opentopography.org/developers)
регулируют доступ к сервису. Опубликованные лимиты бесплатных ключей
на момент интеграции составляют 50 запросов за 24 часа для обычного
пользователя и 200 для академического; для коммерческого программного
продукта сервис требует Enterprise key. Бесплатный персональный ключ
нельзя использовать как общий ключ многопользовательского приложения.
Для такого развёртывания получите у OpenTopography ключ, разрешающий
серверный доступ от имени пользователей.

## Доступ и вычисления

Edge Function запрашивает одно окно AAIGrid через OpenTopography Global DEM
API с параметром SRTMGL1. Сервис возвращает растровый фрагмент по bbox,
включая окно, пересекающее обычные границы тайлов. Сервер добавляет по две
ячейки к границе bbox и обрезает запрос по пределам широтного покрытия.
В расчёте используются только центры ячеек внутри сохранённого полигона
с исключением внутренних колец. Ячейки за границей могут участвовать только
в оценке производной у граничного центра. Для пересечения линии перемены
дат расчёт недоступен.

Уклон по центру рассчитывается центральными разностями между западным и
восточным и между северным и южным соседями. Для одного шага сетки с
угловой величиной d в радианах и широты φ используются расстояния
dx = N cos(φ) d и dy = M d. N и M — радиусы кривизны эллипсоида WGS84
в первом вертикале и меридиане. Угол равен
atan(hypot((east − west) / (2 dx), (north − south) / (2 dy))) в градусах.
NoData в центре или любом из четырёх соседей исключает оценку уклона.
Средние арифметические по центрам ячеек. Это скрининг, а не современная
топографическая съёмка или доказательство эрозии.

Лимиты AGRONA: оценка окна до 12 000 ячеек вместе с запасом для соседей,
не более 1 000 вершин, ответ до 512 КиБ, тайм-аут 12 секунд.
Для статуса «Готово» нужны минимум четыре значения высоты и уклона и
80% покрытия отдельно по каждому показателю. При меньшем покрытии
сохраняются и показываются доступные значения с предупреждением.
Один запрос провайдера на расчёт, без немедленных повторов. Существующий
RPC не позволяет параллельно заказать расчёт для той же ревизии;
после ошибки действует минутная пауза. Общая квота ключа учитывается
у поставщика и делится всеми пользователями этой среды.

## Развёртывание и проверка

1. В целевой тестовой среде проверьте наличие миграций
   `202611140001_foundation.sql` и `202611140003_earth_observations.sql`
   и всех их предшествующих зависимостей. Новая миграция для SRTM не нужна.
   Используются `field_geojson`, `claim_earth_job`, `earth_observation_jobs`
   и `field_analytics.terrain_metrics`.
2. Получите подходящий для вашей среды ключ у OpenTopography и добавьте `OPENTOPOGRAPHY_API_KEY`
   в секреты Supabase Edge Functions в Dashboard либо через
   `supabase secrets set --env-file /absolute/path/to/private-srtm.env --project-ref STAGING_REF`.
   Файл храните вне репозитория.
3. Выполните `supabase functions deploy srtm-terrain --project-ref STAGING_REF`
   и разверните фронтенд. Отдельный worker не нужен.
4. Войдите в тестовый аккаунт и откройте «Аналитика → Почва → Рельеф» для
   сохранённого участка в Казахстане шириной несколько сотен метров.
   Проверьте высоты, средний и максимальный уклон, покрытие и заключение.
5. Перезагрузите страницу. Должна появиться метка кэша. Проверьте в
   `field_analytics` запись с провайдером NASA SRTM, периодом 2000,
   продуктом и ревизией в ключе. Измените границу поля и проверьте новую
   запись. Для большого поля проверьте сообщение о лимите.
