# Модель севооборота AGRONA

Входные данные — история сезонов поля, справочник культур AGRONA, указанный
фермером тип почвы и доступность орошения, выбранный календарный интервал и
дневные данные NASA POWER, если они есть в кэше для этого года и геометрии.
Данные POWER соответствуют ячейке сетки у центра поля. Демо использует
сохранённый сезон 2025 года для исходной границы демонстрационного поля.

## Ограничения и исходный план

Для новых рекомендаций культура должна быть разрешена, отсутствовать в списке
исключений и укладываться в меньшую из указанной доступной длины сезона и
выбранного календарного интервала. В каталоге отсутствуют сортовые пороги и
обязательные местные интервалы возврата, поэтому исторические заморозки,
повторы семейств и остальные климатические сигналы используются как мягкие
ограничения. Исходный план можно просмотреть и при нарушении жёстких условий,
его карточка явно показывает конфликт.

Текущим считается сохранённый план, выбранный пользователем для сравнения.
В его отсутствие точка отсчёта условно повторяет последнюю записанную
культуру или выбирается по общим весам из допустимых планов, если последняя
культура неизвестна. Эти последовательности не записываются в историю.

## Баллы за один сезон

Коэффициенты ниже — правила сравнения MVP. У них нет калибровки по урожайности,
прибыли, вероятности заморозка или вероятности потери урожая.

| Критерий        | Правило                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Почва и история | +1 за культуру с признаком азотфиксации, +1 после азотфиксирующей культуры другого семейства; −2 за соседний повтор семейства и ещё −2 за соседний повтор культуры. За каждую известную историческую запись вычитается 2 за ту же культуру или 1 за то же семейство, делённые на расстояние в годах до старта плана. За повторы семейства в самом плане применяется штраф, равный числу прежних сезонов с этим семейством, делённому на порядковый номер нового сезона. |
| Вода            | Минус нижняя справочная потребность в мм / 100. При полном покрытии осадков дополнительно вычитается положительная разница между этим ориентиром и суммой осадков / 200. Это условный показатель для сравнения. На песчаной и супесчаной почве во время сухого отрезка добавляется половина штрафа за засуху.                                                                                                                                                           |
| Климат          | −2 при превышении культурой наблюдавшегося непрерывного окна без заморозков при полном покрытии минимумов. При наблюдавшейся жаре выше 35 °C и отдельно при полной средней температуре ниже 10 °C вычитается доля сезона, которую занимает культура. При наблюдавшихся ≥14 днях с осадками <1 мм/сут вычитается 2 за низкую или 1 за среднюю засухоустойчивость.                                                                                                        |

Пропущенный день прерывает непрерывный отрезок. Сигнал заморозков определяется
по минимуму ≤0 °C. Пороги скрининга едины для каталога и не заменяют сортовую
оценку. Вес каждого критерия равен 1 или 2 при выборе приоритета. Для поиска
альтернативы её тематический вес увеличивается ещё на 3. На всех карточках
показывается средний балл за сезон при одинаковых пользовательских весах.
Приоритет экономики фиксирует недостающие данные. Доступность орошения
показывается при оценке выполнимости, баллы не предполагают объём воды.

Поиск развивает до 24 лучших частичных планов на каждый год для каждого набора
весов. Хранятся только лучшие продолжения, поэтому рост горизонта не вызывает
полный перебор комбинаций. Поиск приближённый. Дубликаты исключаются из выдачи.
