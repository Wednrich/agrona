# Научные ограничения AGRONA

Аудит PHASE 0, 2026-11-15. AGRONA поддерживает решение, а не гарантирует урожай.

- POWER — исторические gridded estimates, не прогноз и не измеритель микроклимата.
  Сухая серия осадков <1 мм/сут не доказывает дефицит воды в корневой зоне.
  Отсутствующий день прерывает непрерывный отрезок.
- 35 °C, 0 °C, 14 дней и прочие пороги MVP — скрининговые правила.
  Повреждение зависит от культуры, сорта, стадии и экспозиции.
- GDD5 использует общую базу, не проверенную thermal-time модель каждого сорта.
  Season dates — редактируемые ориентиры; сейчас сезон внутри одного года.
- Среднее трёх сохранённых лет не является стандартной климатической нормой.
  Нужны фиксированный baseline, достаточный ряд и сопоставимые параметры.
- NDVI рассчитывается из reflectance; он не измеряет урожай, плодородие,
  влажность или прямое физиологическое здоровье. Изменение двух дат может
  отражать уборку/фенологию. Cloud filtering не исключает все ошибки.
- ≥80% valid pixels и ≥3 даты — эвристики допуска заключения, не confidence
  interval. Маски и support между наблюдениями могут различаться.
- HLS weighted mean всех доступных сцен не является временным средним полного
  года; число снимков/покрытие/partial status обязательны рядом с показателем.
- HLS negative reflectance исключается текущим алгоритмом консервативно;
  влияние этого отбора и верхнего порога нужно проверить по эталонным сценам.
- SRTM отражает поверхность эпохи 2000, EGM96. Уклон — центральная разность
  четырёх соседей с метрическими WGS84 расстояниями, не измеренная эрозия.
  Pixel centres исключают субпиксельную площадь краевых ячеек. DEM может
  включать растительность/строения; мелкий современный дренаж не гарантирован.
- Тип почвы — сведения фермера. Классификации и texture labels сейчас в одном
  MVP поле; они не эквивалентны и не заменяют анализы по глубине.
- Орошение — признак, не подтверждение объёма/качества/надёжности воды.
- Rotation points — документированные эвристики, не yield/profit/probability.
  Beam search ограничен; не доказывает глобальный оптимум. Цена отсутствует.
- Catalogue water/duration/drought характеристики не сортовые гарантии.
  Требуются региональные источники и проверка агрономом. История урожайности
  хранится, но не превращается автоматически в причинную модель.
- При добавлении SMAP — только surface regional context; при ECOSTRESS — LST
  не температура воздуха/листа; при GPM — региональная оценка, не осадкомер поля.

Научная валидация требует исходных растров, независимых контрольных расчётов,
референсных геометрий и agronomic case review. Пройденные unit tests показывают
согласованность реализации на fixtures, но не валидируют прогнозы или эффект
севооборота в полевых условиях.
